# Contributing

Use Node.js 22+, run `npm ci`, then `npm test` and `npm run check`.

For compatibility reports, include your OS, terminal, Node version, agent CLI version, and the visible status wording. Remove prompts, source code, account details and secrets from any screenshots or recordings you share.

Keep automatic detection conservative and ensure prompts remain recoverable with a keypress. Add a deterministic fixture for changes to input forwarding or terminal state. Do not require model credentials for tests.

Contributions are under the Apache 2.0 licence. Report issues at https://github.com/onepunk/matrix-cli/issues.
